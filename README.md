# World Explorer 🌍

World Explorer is a full-stack travel listing web application that allows users to explore, create, update, and manage travel destination listings through a responsive and user-friendly interface.

## 🚀 Features

* Create, edit, update, and delete travel listings
* Responsive UI for desktop and mobile devices
* Dynamic server-side rendering using EJS
* MongoDB database integration for data management
* RESTful routing and structured backend architecture
* Interactive listing management with smooth user experience
* Secure backend handling using Express.js and Node.js

## 📊 Project Statistics

* Managed **32+ travel destination listings**
* Implemented complete **CRUD operations**
* Built using a full-stack architecture with MongoDB integration
* Optimized responsive layout for multiple screen sizes

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/World-Explorer.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd World-Explorer
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Setup Environment Variables

Create a `.env` file and add:

```env
MongoDB_URL=your_mongodb_connection_string
```

### 5️⃣ Run the Application

```bash
npm start
```

or

```bash
npm run dev
```
